# 候风地动仪 · 1:1 三维复原

张衡（东汉阳嘉元年，公元 132 年）候风地动仪的三维复原与原理演示，基于 Three.js，无需构建。

## 运行

浏览器的 ES 模块需要通过 http 访问，双击 `启动.bat`，或：

```bash
python -m http.server 8349
```

然后打开 <http://localhost:8349>。首次加载需联网获取 three.js（jsDelivr CDN）。

## 功能

- **1:1 尺寸**：器身直径 1.85 m（“员径八尺”，东汉尺 23.1 cm），可开启“尺寸标注”查看
- **精细建模**：酒尊形器身与隆起器盖、篆文 / 山 / 龟 / 鸟 / 兽浮雕纹带、云雷纹与连珠纹、八龙（鹿角、须髯、鬣毛、鳞片、背鳍、四爪）、八蟾蜍（疣粒、大张的口）、石台座八方铭文；纹理全部由程序实时生成
- **四种视图**：外观 / 剖视（随视角切开的 1/4 剖面）/ 透视（半透明外壳）/ 分解
- **原理演示**：物理模拟 P 波、S 波与悬垂摆，展示 都柱 → 八道滑杆 → 斜面顶杆 → 牙机（龙颌杠杆）→ 吐丸 → 施关锁定 的完整链条；右侧七步讲解同步高亮，附俯视位移轨迹与地震记录图
- 可设置震中方位与强度；强度过低时会出现“由 S 波误触发”的情形，结果面板会提示
- 快捷键：空格 = 发生地震，R = 复位，1–4 = 切换视图

## 文件

| 文件 | 内容 |
|---|---|
| `js/seismoscope.js` | 地动仪全部几何建模与机构 |
| `js/textures.js` | 程序化纹理（青铜锈、浮雕纹样、鳞、疣、石材） |
| `js/simulation.js` | 地震波与悬垂摆物理模拟（纯逻辑） |
| `js/main.js` | 场景、灯光、交互、模拟与模型联动 |
| `js/waves.js` / `charts.js` / `audio.js` | 地震波着色器、二维图表、合成音效 |

## 说明

原物早已失传，本模型依据《后汉书·张衡传》记载及 2005 年“悬垂摆”复原思路重建，内部机构为示意设计；模拟中的位移与时间均经放大处理。
